## 软件介绍

途视的核心本质是 **批量跑工作流**：把你要处理的内容组织成"项目 + 分镜"的结构，然后一键让整批分镜依次通过你配置好的工作流（本地 ComfyUI / RunningHub 等），自动喂入数据、自动取回结果、自动整理归档。

它的价值在于：

- **批量** — 一条工作流可以一次性作用到几十上百个分镜，不用一个个手工跑
- **流水线** — 文本 → 提示词 → 生图 → 生视频 → 配音 → 后期，各环节都是工作流，可串起来一键跑完
- **灵活** — 工作流完全由你自定义（只要 ComfyUI 兼容即可），软件只负责调度、传参、回收结果
- **多平台** — 同一套流程可切换到本地 ComfyUI、RunningHub 或其它云端通道运行

常见的用法（工作流具体是什么，由你配置决定）：

- 文字类工作流：改写、翻译、LLM 推理、分镜/剧本/角色生成
- 图像类工作流：文生图、图生图、换脸、放大、反推提示词
- 视频类工作流：文生视频、图生视频、对口型、动作迁移、首尾帧
- 音频类工作流：TTS 配音、音乐
- 3D 类工作流：模型生成

### 使用场景

| 使用场景 | 途视能做什么 |
|---------|-------------|
| **漫剧 / 动态漫画** | 输入小说原文，自动分章分镜 → 批量生成画面 → 图生视频 → 配音 → 导出剪映草稿 |
| **短剧** | 从剧本到分镜、生图、生视频、对口型、放大，全自动批量产出 |
| **解说 / 资讯类视频** | 文案 → 配图 → 配音 → 成片，批量生成解说内容 |
| **视频二创 / 风格参考** | 导入参考视频，自动切分镜头、抽关键帧、反推提示词，再批量生成同风格画面 |
| **小说可视化** | 文字转分镜画面，制作视频小说 |

> 软件自带"正推 / 反推"两套组织方式：**正推**从一段文本出发批量产出内容；**反推**从参考视频出发，分割场景、抽关键帧、反推提示词后再接入批量生成。两者最终都落到"分镜 → 批量跑工作流"这个核心上。

## 正推基本流程

### 半自动流程（精细控制）

```
粘贴文本 → 分章 → 生成剧本 → 生成分镜 → 编辑角色 → 筛选场景批量文生图
→ 筛选人物批量文生图 → 选择音频（可选）→ 分镜生图 → 多图/多视频拆分（可选）
→ 配音（可选）→ 图生视频 / 首尾帧生视频 → 视频对口型（可选）→ 放大（可选）→ 导出
```

### 全自动流程（一键生成）

```
粘贴文本 → 自动分镜 → 选择模板 → 调整提示词 → 开始运行
→ 视频对口型（可选）→ 放大（可选）→ 导出
```

### 正推核心功能说明

| 功能 | 描述 |
|------|------|
| 自动分章 | 按"第X章"正则把文本拆分为章节页签 |
| 生成小说/剧本 | LLM 对原文改写润色、生成剧本格式 |
| 生成分镜 | LLM 返回 JSON 分镜表（场景/角色/对话/画面提示词/视频提示词/时长），自动建分镜 |
| 角色编辑 | 统一管理角色参数（提示词、LoRA、配图、模型3D），推理角色自动建库并挂到分镜 |
| 批量文生图 | 一键操作支持：跳过已完成 / 全部 / 奇数 / 偶数 / 仅首个镜头 |
| 多图/多视频 | 一个分镜可挂多张配图、多个视频，可一键拆分为多个独立分镜 |
| 配音 | 通过 ComfyUI 工作流生成配音，可选操作 |
| 图生视频 | 支持文生视频、图生视频、视频生视频、首尾帧生视频 |
| 对口型/放大 | 通过 RunningHub 模型 API（如 kling-lip-sync）或对应工作流完成 |

> **备注**：推理中心默认使用 RH 免费模型（效果下限），如需更高质量请自行搭建对应工作流或使用付费模型。

## 反推基本流程

```
导入视频 → 调整分割阈值 → 自动场景分割 → 抽关键帧作参考图
→ OCR 识别字幕文本（可选）→ 参考图生图 / 提示词反推 → ...对接正推流程
```

- **场景分割**：基于 FFmpeg 场景检测自动切分视频（可调阈值、最短/最长片段时长），也可整段使用
- **抽关键帧**：按时间间隔截取视频帧作为参考图
- **字幕识别**：本地 OCR（PPOCRv5）识别视频/图片中的文字，作为原文进入正推流程

> **备注**：反推与正推同属一个框架，操作可无缝对接。所有流程可根据需求自行调整提示词和工作流。

## 工作流配置

### 支持的模型与平台

途视支持调用以下所有主流模型，灵活控制成本与效果：

| 类型 | 支持平台/模型 |
|------|-------------|
| **免费模型** | RunningHub 免费模型 |
| **国内主流** | 豆包、可灵、即梦、海螺（MiniMax）、Vidu |
| **国际主流** | Sora、大香蕉（BigBanana）等 |
| **通用工作流** | 所有 ComfyUI 兼容工作流 |

### 工作流分类

`外部工作流（API）/` 下每个子目录对应软件中的一个功能按钮。工作流可按类型分类：

| 分类 | 工作流类型 |
|------|-----------|
| **生图** | 文生图、图生图、换脸、换装、图片编辑、放大 |
| **视频** | 文生视频、图生视频、视频生视频、换脸、首尾帧、口型、动作迁移、背景音、放大 |
| **推理** | 推理中心、生成小说、生成剧本、生成分镜、推理角色 |
| **其它** | 提示词、提示词2、模型3D、音频、原文、原文改 |

### 工作流绑定规则

工作流通过**节点标题**自动识别输入输出：

- 输入节点标题格式：`输入-数据来源-数据类型`（如 `输入-当前镜头-提示词`），支持原文/提示词/配图/参考图/参考视频/音频/角色等 30+ 种输入类型
- 输出节点标题格式：`输出=配图`（图片、视频、音频、文本、模型3D 均可作为输出）
- 数据来源：当前镜头 / 上一镜头 / 下一镜头 / 收藏角色 / 项目角色 / 自定义

### ComfyUI 工作流配置（本地使用）

1. 在 ComfyUI 浏览器中跑通工作流
2. 导出为 **API 格式**，放置到 `外部工作流（API）/` 对应目录（一个功能按钮对应一个文件夹）
3. 软件内绑定输入参数（支持跨镜头、选角色）与输出节点
4. 蓝色框为工作流字段默认参数，黄色为已修改参数

### RunningHub 工作流配置（云端）

1. 在 RunningHub 分配/绑定工作流（软件内可浏览、搜索工作流模板与 AI 应用）
2. 配置 RunningHub API Key
3. 查看工作流绑定的输入参数，在软件内填充

### SDWebUI 支持功能

> SDWebUI 不再增加新功能，目前支持：生图、放大、LoRA、ControlNet 控图、图片 WD 反推提示词

### 额外参数

支持自定义参数（帧率、时长、文本、本地资源路径等），需先在设置中配置，分镜中不输入则走工作流默认。

## AI 推理

途视内置 LLM 推理能力，用于文本改写、提示词提取、角色抽取、分镜生成。推理统一通过 **ComfyUI 工作流** 完成（在 `外部工作流（API）/` 对应目录放置对应工作流即可）：

| 推理类型 | 输入 | 输出 | 用途 |
|---------|------|------|------|
| 原文改 | 当前页/当前章原文 | 改写文本 | 润色、精简 |
| 提示词 | 原文改 | 画面提示词 | 文生图用 |
| 提示词2 | 提示词 | 翻译文本 | 生成英文提示词 |
| 推理角色 | 原文当前页 | 角色设定（自动建角色库） | 人物管理 |
| 生成小说 | 综合数据+模板 | 小说正文 | 章节文本 |
| 生成剧本 | 综合数据+模板 | 剧本文本 | 剧本格式 |
| 生成分镜 | 综合数据+模板 | 分镜表（场景/对话/画面提示词/视频提示词） | 自动分镜 |
| 推理中心 | 图文音视频+角色+工作流 | AI 决策（自动操作镜头/角色并调工作流） | 全自动创作 |

## 配音

配音统一通过 **ComfyUI 工作流** 完成（`音频` 分类）：输入文本 → TTS 工作流节点 → 输出音频文件。

- 每个分镜可指定**音频角色**（与画面角色分离），支持全局音色
- 支持音量、语速调整，以及视频时长对齐音频（自动变速）

## 项目界面说明

### 视图

| 视图 | 说明 |
|------|------|
| **列表视图** | 分镜平铺列表，逐条操作 |
| **面板视图** | 分镜面板，图文并排 |

### 分镜管理

- **红色背景**：当前未完成；**绿色背景**：已完成
- 显示当前分镜的图片数量、视频数量及工作流运行时长
- 分镜支持：上移/下移、插入、删除、复制、**合并**（拼接视频/音频/文本）、**分割**（多图/多视频拆分子分镜）、交换

### 图片/视频管理

图片与视频为**两个独立的管理区域**，各自可添加、删除、选中、复制参考：

- **图片**：一个分镜可挂多张配图，支持遮罩编辑、简笔画、取景等
- **视频**：一个分镜可挂多个视频，支持裁剪、调速、倒放、抽帧、调分辨率/帧率
- 文生视频未传入图片时，生成成功后会自动创建首帧图
- 分镜还支持参考图、参考视频、模型3D

### 高级操作

- **图片编辑**：进入详情，支持遮罩编辑、简笔画、360 取景
- **视频拼接**：通过分镜"向上合并"拼接视频（建议在视频放大后操作，避免视频过长导致处理失败）
- **资源选择**：支持本地图片/视频/音频，也可选择上下分镜的图片，时间秒参数灵活控制取帧
- **一键操作**：顶部一键把原文→提示词、提示词→提示词2，或批量清图/清视频/清配音/清参考，可应用全局或单章

### 剪映草稿特效

- **镜头动画**：入场 / 出场 / 组合动画，支持随机、顺序、固定三种方式
- **转场**：镜头间转场效果
- **位移动画**：左右/上下关键帧位移
- **镜头特效**：剪映内置特效（资源 ID 标识）
- **字幕**：按原文改自动生成字幕轨，可设颜色、字号、位置
- **片头片尾**：片头文本、全片文字、片尾视频、片尾音乐（可循环）

### 导出设置

- **单文件几镜头**：一个视频包含几个分镜
  - 设置为 `9999`：这一章合并为一个视频
  - 设置为 `1`：每个分镜导出独立视频
- **章节合并**：合并章节输出
- **视频时长对齐音频**：自动给视频变速对齐配音时长
- 右侧显示预计导出数量、总时长、总分镜数

## 命令行 CLI

界面之外，途视还提供一个命令行入口：`ExePack/途视CLI.exe`。它让脚本、批处理和 AI Agent 直接驱动创作全流程——**导演在外面，工厂在途视里**：外部负责决定"跑什么"，工作流调度、素材回收、导出仍由途视完成。

### 工作方式

```
命令行 / 脚本 / AI Agent
        │  POST {"cmd":"shot gen","args":{...}}
        ▼
途视主程序内置服务 127.0.0.1:19112   ← 需先启动 途视/途视.exe 并保持运行
        │
        ▼
工作流执行 → 素材归档 → 导出
```

- CLI 本身不干活，只做转发，**前提是途视主程序处于运行状态**（首次跑通常要先 `login`）
- 默认端口 `19112`；主程序可用 `途视.exe --aicli-port 19212` 换端口，`--aicli-token xxx` 开启鉴权（开启后命令需带 `--token xxx`）
- **所有输出都是一行 JSON**，看 `ok` 判断成败，进程退出码 0 / 1
- 生成、导出等长任务返回 `jobId`，默认立即返回，加 `--wait` 会轮询到结束

### 用法

```bash
ExePack\途视CLI.exe <命令> [key=value ...] [JSON对象] [选项]
```

| 选项 | 说明 |
|------|------|
| `--json '{...}'` | 用 JSON 传参数，数组/嵌套结构走这条路 |
| `--arg key=value` | 追加单个参数，可重复 |
| `--wait` | 轮询长任务直到结束（默认直接返回 jobId） |
| `--poll 2` | `--wait` 的轮询间隔，秒（默认 2） |
| `--timeout 600` | `--wait` 最长等待秒数，0 = 不限 |
| `--port` / `--host` / `--url` | 指定服务地址 |
| `--token` | 鉴权 token（主程序开启鉴权时） |

命令名不区分大小写，`shot.gen`、`Shot_Gen`、`shot gen` 等价。参数拿不准就用**自省**：

```bash
ExePack\途视CLI.exe help                      # 列出全部命令
ExePack\途视CLI.exe schema name="shot creates"  # 查某个命令的参数（带中文说明）
```

### 命令一览

| 分组 | 命令 | 说明 |
|------|------|------|
| **连接 / 自省** | `help`、`schema`、`system status`、`login`、`ui main` | 命令总览、参数说明、探活、登录、唤起主界面 |
| **设置** | `setting get` / `setting set` / `setting list` | 读写配置项（如剪映草稿路径） |
| **项目** | `project list` / `get` / `create` / `set` / `delete` / `progress` | 项目增删查与进度 |
| | `project key add` / `list` / `delete` | 章节（页签）管理 |
| | `project handoff get` / `set`、`project setsound` | 交接信息、全局音色 |
| **模板** | `template list` / `get` | 项目模板 |
| **角色** | `role creates` / `list` / `get` / `set` / `gen` / `stop` / `copy` / `bind` / `res` / `delete` | 角色库与批量定妆出图 |
| **分镜** | `shot creates` / `list` / `get` / `set` / `gen` / `stop` / `insert` / `delete` / `trim` / `res` / `frame` | 分镜增删改查、批量跑生成、资源与接续管理 |
| | `shot setsound` / `shot setaudiorole` / `shot setusevideo` | 台词音、配音角色、是否采用视频 |
| **工作流** | `workflow list` / `get` / `inputs` | 工作流清单（需带模板名）与输入输出 |
| | `workflow temp list` / `get` / `set` | 模板工作流 |
| | `workflow param list` / `set` / `bind`、`workflow customize list` / `set` / `delete` | 参数绑定与自定义参数 |
| | `workflow intype list`、`workflow out type list`、`workflow out set` | 输入 / 输出类型 |
| **运行** | `run preview` / `status` / `list` / `qa` | 提交预览、按 jobId 查进度、导出前质检 |
| **导出** | `export draft`、`export video` | 剪映草稿 / mp4 成片 |
| **音频** | `sound list` / `get` / `create` / `set` / `delete`、`sound tab list` / `create` | 音色与音色分类 |

### 典型流程

```bash
ExePack\途视CLI.exe login
ExePack\途视CLI.exe project create projectName="我的短片"
ExePack\途视CLI.exe role creates projectName="我的短片" --json '{"roleItems":[{"name":"阿岚"}]}'
ExePack\途视CLI.exe role gen projectName="我的短片" workflowSn=6102 --json '{"roleSn":[1]}'
ExePack\途视CLI.exe shot creates projectName="我的短片" --json '{"shotItems":[{"dialogue":"……","imagePrompt":"……","videoPrompt":"……"}]}'
ExePack\途视CLI.exe shot list projectName="我的短片"
ExePack\途视CLI.exe shot gen projectName="我的短片" workflowSn=10401 --json '{"shotSn":[1,2,3]}' --wait
ExePack\途视CLI.exe run qa projectName="我的短片"
ExePack\途视CLI.exe export draft projectName="我的短片" --wait
```

`workflowSn` 从 `workflow list` 拿，`roleSn` / `shotSn` 分别从 `role list` / `shot list` 拿。生成类命令返回 `jobId` 后，可用 `run status jobId=xxx` 查进度。

### 适用场景与注意

- **适合**：批量脚本、定时任务、外部 AI Agent 驱动全自动产出；多人协同时用 CLI 走非交互链路
- **先自省后动手**：参数以 `schema` 为准；`shot creates` 的提示词字段是 `imagePrompt` / `videoPrompt`，字段名写错会返回成功但内容为空，提交后建议 `shot get` 回读抽查
- Windows 控制台（PowerShell）直调偶发吞输出，脚本里建议用 Python `subprocess` 调用并按 UTF-8 读取
- CLI 是对同一套界面能力的外部调用，**没有独立的账号体系**，用的是主程序当前的登录状态与项目文件

## 常见问题

### Q: 必须使用本地 ComfyUI 吗？

不是必须的。可以使用仙宫云、优云智算、RunningHub 等云端服务，无需本地配置。

### Q: 工作流如何配置？

本地使用需在 ComfyUI 浏览器中跑通工作流，导出 API 格式放到对应目录。一个功能按钮对应一个文件夹。
云端使用分配完工作流，然后查看里面绑定下软件里面的输入参数。

### Q: 红色标记是什么意思？

代表未连接对应后端（ComfyUI / RunningHub / SDWebUI），或连接后未找到对应文件。

### Q: 反推和正推可以混用吗？

可以。反推流程与正推同属一个框架，操作可无缝对接。

### Q: CLI 命令没反应 / 连不上怎么办？

先确认主程序已启动：`途视CLI.exe system status` 能返回 JSON 即服务在线。改过端口或端口被占用时，主程序用 `途视.exe --aicli-port 19212` 指定，命令侧 `--port 19212` 跟上；端口占用者会写在启动日志里。

### Q: 推理、翻译、配音用什么后端？

统一走 **ComfyUI 工作流**。在 `外部工作流（API）/` 对应目录放置推理 / 翻译 / 配音工作流，软件内选择对应工作流即可。翻译结果写入"提示词2"，用于生成英文提示词。
